# תיקיית נכסים (assets)

המשחק רץ מיד **בלי** קבצי תמונה או סאונד חיצוניים — הדמות, הפחים, הלכלוך,
הבקבוקים והכלב מצוירים ב-SVG / אימוג'י ישירות בקוד. התיקייה הזו מיועדת לכם,
כדי להחליף את ה"פלייסהולדרים" באומנות האמיתית בהמשך.

## החלפת דמות ניקי האמיתית

1. שמרו את התמונה כאן, למשל `assets/nicky.png` (רקע שקוף, PNG או SVG).
2. ב-`index.html`, *לפני* שאר קבצי ה-JS, הוסיפו שורה:

   ```html
   <script>window.NICKY_IMAGE = 'assets/nicky.png';</script>
   ```

3. זהו — כל מקום במשחק שבו מופיעה ניקי ישתמש אוטומטית בתמונה האמיתית
   במקום בדמות ה-SVG (ראו `js/nicky.js`).

## החלפת צלילים

הצלילים נוצרים בקוד בעזרת Web Audio API (`js/audio.js`).
כדי להשתמש בקבצי שמע אמיתיים, החליפו את גוף הפונקציות `sfx()` /
`tone()` בטעינת קובץ, למשל:

```js
new Audio('assets/collect.mp3').play();
```

ה-API החיצוני (`Audio.sfx('collect')` וכו') יכול להישאר זהה.

## נכסים שאפשר להוסיף כאן בהמשך
- `nicky.png` – דמות ניקי האמיתית
- `bin.svg`, `dog.svg` – פח וכלב
- `music.mp3`, `collect.mp3`, `correct.mp3` – מוזיקה ואפקטים
