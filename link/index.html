חיבור ל-GitHub

הקישורים נשמרים בקובץ במאגר שלכם ב-GitHub. כדי לשמור, צריך "טוקן" (מפתח גישה) פעם אחת:

  1. היכנסו ל-יצירת טוקן ב-GitHub.
  2. תנו שם (למשל "מקצר קישורים") ותוקף.
  3. ב-Repository access בחרו Only select repositories ואת המאגר tiratcarmel2026/-.
  4. ב-Permissions → Repository permissions → Contents בחרו Read and write.
  5. לחצו Generate token, העתיקו והדביקו כאן.

הטוקן נשמר רק בדפדפן הזה ולא נשלח לשום מקום חוץ מ-GitHub.
