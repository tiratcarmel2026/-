# סוכנות הדיגיטל של טירת כרמל 🌿

אפליקציה עצמאית (שרת + לוח בקרה) שפועלת כ"עובדת תוכן דיגיטלי" של
עיריית טירת כרמל: כל שעה עגולה היא מייצרת רעיונות לפוסטים עם טקסט מוכן,
רעיונות/פרומפטים לגרפיקה, וסיכום מגמות ותגובות מהרשתות החברתיות של העירייה.

> ⚠️ זו לא אפליקציית דף-סטטי כמו שאר הפרויקט הזה (ה-README הראשי, המשחק
> "ניקי") — היא צריכה שרת שרץ ברציפות (Node.js), ולכן **לא ניתן** להריץ
> אותה על GitHub Pages. יש לארח אותה בשירות שתומך בתהליך ארוך-טווח,
> למשל Railway, Render, Fly.io, VPS רגיל, או שרת פנימי של העירייה.

## מה האפליקציה עושה

בכל שעה עגולה (00:00, 01:00, 02:00...) לפי אזור הזמן `Asia/Jerusalem`:

1. שולפת פעילות אחרונה מהרשתות החברתיות של העירייה (פוסטים + תגובות).
2. שולחת את הנתונים ל-Claude API עם הנחיות טון/מיתוג של העירייה.
3. מקבלת בחזרה: 3 רעיונות לפוסטים עם טקסט מוכן לפרסום, פרומפט/תיאור
   גרפיקה לכל רעיון, וסיכום מגמות + רשימת תגובות שחשוב שאיש/אשת צוות
   יראו (תלונות, בעיות בטיחות, שאלות דחופות וכו').
4. שומרת את התוצאה ומציגה אותה בלוח הבקרה (`/`), עם היסטוריה של כל
   העדכונים הקודמים. אפשר גם ללחוץ "צור תוכן עכשיו" כדי להריץ ידנית בלי
   לחכות לשעה העגולה.

## הרצה מקומית

```bash
cd digital-agency-app
npm install
cp .env.example .env
# ערכו את .env והוסיפו לפחות את ANTHROPIC_API_KEY
npm start
```

לאחר מכן פתחו את `http://localhost:3000`.

להרצה עם ריענון אוטומטי בזמן פיתוח: `npm run dev`.

## הגדרות חובה

| משתנה | הסבר |
|---|---|
| `ANTHROPIC_API_KEY` | מפתח API של Anthropic (Claude). בלעדיו לא ניתן ליצור תוכן. השיגו אותו בכתובת https://console.anthropic.com/ |
| `ANTHROPIC_MODEL` | ברירת מחדל `claude-sonnet-5`. ניתן לשנות למודל אחר אם צריך. |

## חיבור לרשתות חברתיות אמיתיות (אופציונלי)

כרגע, כשאין הרשאות ניהול לעמודי הרשתות החברתיות, המערכת עובדת **במצב
דמו**: היא משתמשת בנתוני דוגמה (`server/services/socialProviders/mockProvider.js`)
כדי שכל שאר המערכת (יצירת תוכן, ניטור תגובות, לוח הבקרה) תעבוד קצה-לקצה.
זה מסומן בבירור בלוח הבקרה ("מצב דמו").

כדי לחבר את עמוד הפייסבוק/אינסטגרם האמיתי של העירייה:

1. הפכו את חשבון הפייסבוק לעמוד עסקי (Page) אם עדיין לא, וחברו אליו את
   חשבון האינסטגרם העסקי (Instagram Business/Creator) דרך Meta Business
   Suite — כך אפשר לגשת גם לאינסטגרם דרך אותו טוקן.
2. צרו אפליקציית Meta ב-https://developers.facebook.com/ וקבלו
   **Page Access Token** עם ההרשאות: `pages_show_list`,
   `pages_read_engagement`, `pages_read_user_content`.
   מומלץ להחליף לטוקן ארוך-טווח (long-lived token).
3. מצאו את ה-`Page ID` של עמוד העירייה (מופיע בהגדרות העמוד או דרך
   Graph API Explorer).
4. הוסיפו ל-`.env`:
   ```
   FB_PAGE_ID=<page id>
   FB_PAGE_ACCESS_TOKEN=<page access token>
   ```
5. הפעילו מחדש את השרת. לוח הבקרה יראה "מחובר לפייסבוק/אינסטגרם אמיתי"
   במקום "מצב דמו".

המימוש נמצא ב-`server/services/socialProviders/facebookProvider.js` ומושך
פוסטים ותגובות אחרונים מהעמוד דרך Graph API. אם בעתיד תרצו להוסיף גם
X/TikTok, הוסיפו ספק נוסף עם אותו ממשק (`fetchRecentActivity()`) ורשמו
אותו ב-`socialProviders/index.js`.

## פריסה לשרת אמיתי

כל שירות שתומך ב-Node.js ותהליך ארוך-טווח יתאים, למשל:

- **Railway / Render**: חברו את הריפו, הגדירו Root Directory =
  `digital-agency-app`, Build Command = `npm install`, Start Command =
  `npm start`, והוסיפו את משתני הסביבה מ-`.env.example` בפאנל ה-Secrets.
- **VPS** (עם pm2 או systemd): `npm install --production && pm2 start server/index.js --name tirat-carmel-agency`.

חשוב: כדי שהשעה העגולה תחושב נכון, ודאו ש-`TZ=Asia/Jerusalem` מוגדר
בסביבת הריצה.

## מבנה הפרויקט

```
digital-agency-app/
├── server/
│   ├── index.js              # שרת Express + הפעלת התזמון
│   ├── scheduler.js           # cron שעתי + הרצה ידנית
│   ├── db.js                  # שמירת היסטוריית תוכן (קובץ JSON)
│   ├── routes/api.js          # /api/batches, /api/generate, /api/status
│   └── services/
│       ├── anthropic.js       # קריאה ל-Claude API
│       ├── contentGenerator.js # בניית הפרומפט ופענוח התשובה
│       └── socialProviders/   # mock + facebook (adapter pattern)
├── public/                    # לוח הבקרה (HTML/CSS/JS ללא build step)
└── data/                      # נשמר כאן batches.json בזמן ריצה (לא ב-git)
```

## מגבלות ידועות

- ללא `FB_PAGE_ID`/`FB_PAGE_ACCESS_TOKEN` הניטור הוא על נתוני דוגמה בלבד —
  אין כרגע סריקה של תוכן אמיתי.
- אין כרגע פרסום אוטומטי לרשתות (המערכת רק *מציעה* תוכן; הפרסום עצמו
  צריך להתבצע ידנית או דרך הרחבה עתידית עם הרשאות פרסום).
- יצירת תמונות בפועל אינה כלולה — המערכת מייצרת *תיאור/פרומפט* לגרפיקה,
  שאותו אפשר להזין לכלי עיצוב/AI-לתמונות או להעביר למעצב.
