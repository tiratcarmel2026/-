# ניקי שומרת על הניקיון 🧹♻️🐶

משחק וידאו לדפדפן לילדים (גילאי 4–8), בנושא שמירה על ניקיון העיר, של
**עיריית טירת כרמל**. הכוכבת היא **ניקי** — בובה חמודה עם שיער כתום,
סרבל ג'ינס ונעלי ספורט ירוקות — שמלמדת ילדים לשמור על העיר נקייה.

> *"כל אחד יכול לעזור לשמור על העיר נקייה!"*

---

## 🎮 איך משחקים

המשחק כולל תפריט ראשי ושלושה שלבים, וכל שלב מלמד שיעור אחד:

| שלב | שם | מה עושים | מה לומדים |
|----|----|---------|----------|
| 1 | **פינוי אשפה** | לוחצים על הלכלוך ברחוב כדי לזרוק אותו לפח הירוק | אוספים אשפה ושומרים על הרחוב נקי |
| 2 | **מיון מיחזור** | **גוררים** כל פריט לפח הנכון: זכוכית ובקבוקים / אשפה רגילה | זכוכית ובקבוקים הולכים למיחזור |
| 3 | **אוספים אחרי הכלב** | לוחצים על הקקי כדי לאסוף לשקית, ואז לוחצים על הפח | תמיד אוספים אחרי הכלב |

- כל שלב קצר וניתן לניצחון, וזוכים ב-**1–3 כוכבים** לפי מהירות/דיוק.
- **אין מסכי כישלון** — תשובה שגויה נותנת רמז עדין ולא עונש.
- ההתקדמות (כוכבים) נשמרת אוטומטית בדפדפן (`localStorage`).
- בין השלבים ניקי מציגה טיפ קצר, עם כפתור **🔊 הקראה** (קול עברי אם זמין בדפדפן).

---

## ▶️ איך מריצים

זהו אתר סטטי בלי שרת. אפשר פשוט:

1. **לפתוח ישירות** — לחצו פעמיים על `index.html` (ייפתח בדפדפן).
2. **או להריץ שרת מקומי** (מומלץ, כדי שכל התכונות יעבדו חלק):

   ```bash
   # מתוך תיקיית הפרויקט
   python3 -m http.server 8000
   # ואז פתחו בדפדפן:  http://localhost:8000
   ```

   או עם Node:

   ```bash
   npx serve .
   ```

המשחק מותאם לטלפון בתצוגה לאורך (portrait), עם כפתורים גדולים ונוחים למגע.
עובד גם עם עכבר במחשב.

> 💡 הצליל והמוזיקה נדלקים אחרי הנגיעה/לחיצה הראשונה (דרישת הדפדפנים).

## 📁 מבנה הפרויקט

```
.
├── index.html          # נקודת הכניסה — טוען את כל הקבצים
├── css/
│   └── styles.css      # כל העיצוב, RTL, מותאם לנייד
├── js/
│   ├── nicky.js        # דמות ניקי (SVG לשימוש חוזר)
│   ├── audio.js        # צלילים, מוזיקה והקראה (Web Audio + SpeechSynthesis)
│   ├── game.js         # מנוע ראשי: תפריט, ניווט מסכים, כוכבים, קונפטי
│   ├── level1.js       # שלב 1 — פינוי אשפה
│   ├── level2.js       # שלב 2 — מיון מיחזור
│   └── level3.js       # שלב 3 — אוספים אחרי הכלב
├── assets/
│   └── README.md       # איך להחליף לאומנות וצלילים אמיתיים
└── README.md           # הקובץ הזה
```

כל שלב הוא מודול עצמאי שנרשם על `window.Levels[n]` עם הממשק
`{ start(api, finish), stop() }`, כך שקל להוסיף שלבים חדשים.

## 🎨 החלפת אומנות וצלילים אמיתיים

המשחק רץ מיד עם פלייסהולדרים (SVG/אימוג'י), אבל בנוי כך שאפשר להחליף
בקלות לאומנות אמיתית:

### דמות ניקי
שמרו תמונה ב-`assets/nicky.png` והוסיפו ב-`index.html` *לפני* שאר ה-JS:

```html
<script>window.NICKY_IMAGE = 'assets/nicky.png';</script>
```

כל המשחק יציג אוטומטית את התמונה האמיתית במקום ה-SVG.

### צלילים
ראו הסבר מלא ב-[`assets/README.md`](assets/README.md).
