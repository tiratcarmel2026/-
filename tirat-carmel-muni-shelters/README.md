# מקלטים, מחסות ומיגוניות — טירת כרמל

אתר של **אגף ביטחון וחירום, עיריית טירת כרמל**. הוא מציג את 61 המרחבים המוגנים בעיר: 33 מקלטים ומחסות ו-28 מיגוניות.

## מה יש באתר
- **המקלט הקרוב אליי**: התושב משתף מיקום, ומיד מוצגים המרחב המוגן הקרוב, זמן הגעה בהליכה ובהליכה מהירה, מרחק, ו-3 חלופות קרובות. אם התושב כבר אישר מיקום בעבר, האיתור מתבצע אוטומטית בפתיחת האתר.
- **מיקום חי**: אחרי האישור, המיקום מתעדכן אוטומטית תוך כדי תנועה, וכך גם המקלט הקרוב, זמן ההגעה והרשימה. מחוון ירוק מראה מתי העדכון האחרון.
- **הפעלת מיקום**: אם המיקום חסום או ששירותי המיקום בטלפון כבויים, מוצגות הוראות מותאמות לאייפון ולאנדרואיד. האתר בודק שוב לבד, כל כמה שניות ובכל חזרה מההגדרות, ומתעדכן ברגע שהמיקום הופעל. אין צורך ללחוץ שוב.
- **בלי GPS**: בוחרים רחוב מהרשימה או מקישים על המפה.
- **ניווט**: כפתורי ניווט בוויז ובגוגל מפות (במצב הליכה) לכל מקלט.
- **שיתוף**: שיתוף האתר, שיתוף המיקום הנוכחי, שיתוף המקלט הקרוב, ושיתוף בוואטסאפ.
- **פנייה למוקד 106**: טופס שפותח הודעת דוא״ל מוכנה ל-`moked@tirat-carmel.muni.il`, עם נושא, פרטי קשר, המקלט הרלוונטי ומיקום הפונה. יש גם כפתור להעתקת הפנייה וחיוג ישיר ל-106.
- מספרי חירום, מצב כהה, תצוגה לטלפון ולמחשב, ועבודה ללא אינטרנט (אחרי ביקור ראשון).

## מבנה
| קובץ | תפקיד |
|---|---|
| `index.html`, `css/app.css`, `js/app.js` | האתר |
| `data/shelters.js` | נתוני המקלטים (נוצר אוטומטית; אין לערוך ידנית) |
| `tools/source.tsv` | **מקור הרשימה**: כאן מוסיפים, מוחקים או מעדכנים מקלט |
| `tools/build_data.py` | בונה את `data/` מהמקור |
| `tools/build_artifact.py` | יוצר עמוד HTML יחיד ועצמאי לשיתוף תצוגה מקדימה |
| `sw.js`, `manifest.webmanifest` | עבודה ללא אינטרנט והתקנה כאפליקציה |

## עדכון הרשימה
1. עורכים את `tools/source.tsv`. העמודות: סוג (`shelter` או `protected`), רחוב כפי שמוצג, מספר, שם הרחוב ב-OpenStreetMap, ותיאור.
2. מריצים `python3 -I tools/build_data.py`.

## דיוק המיקומים במפה — חשוב
ב-OpenStreetMap אין מספרי בתים לטירת כרמל, ולכן:
- **7 מקלטים** ממוקמים במדויק לפי מבנה מוכר: קניון לב העיר, בי״ס יגאל אלון, בי״ס זבולון, בי״ס דגניה, קופת חולים כללית וצומת נתן אלבז–גורדון.
- **52** מוצגים במרכז הרחוב ומסומנים „מיקום משוער". המרחק והזמן שמוצגים עבורם הם הערכה.
- **2** לא מסומנים במפה, כי הרחובות לא קיימים ב-OSM: השריון 14 והרב משה מרדכי 7.

**הניווט בוויז ובגוגל תמיד נעשה לפי הכתובת המלאה**, ולכן הוא מדויק גם כשהסמן במפה משוער.

**כך מתקנים מיקומים (מומלץ לפני השקה):** פותחים את האתר עם `?edit=1` בסוף הכתובת, גוררים כל סמן למיקום המדויק, לוחצים „העתקת התיקונים", שומרים את הטקסט כ-`tools/fixes.json` ומריצים `python3 -I tools/build_data.py`.

## הרצה מקומית
```bash
cd tirat-carmel-muni-shelters && python3 -m http.server 8000   # http://localhost:8000
```
שיתוף מיקום בדפדפן עובד רק בכתובת `https` או ב-`localhost`.

## בדיקות
```bash
cd tirat-carmel-muni-shelters && node tests/location.test.js
```
הבדיקה מכסה: איתור אוטומטי, עדכון בזמן תנועה, הפסקת מעקב, מיקום חסום שאושר בהגדרות, ושירותי מיקום כבויים שהופעלו.
