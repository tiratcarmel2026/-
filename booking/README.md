# קביעת תורים אונליין — עיריית טירת כרמל

אתר סטטי (בלי שרת) לקביעת תורים מקוונת עבור כל מחלקות העירייה: התושב בוחר
מחלקה, תאריך ושעה מתוך שעות הקבלה שהוגדרו, המשבצת "נשמרת" עבורו ל-15 דקות
בזמן שהוא ממלא את פרטיו, ובסיום נשלחת הודעת מייל למחלקה הרלוונטית ואישור
לתושב, וניתן גם להוריד קובץ ליומן (`.ics`).

## איך מריצים

```bash
cd booking
python3 -m http.server 8000
# פתחו בדפדפן: http://localhost:8000
```

או פשוט לפתוח את `booking/index.html` ישירות בדפדפן.

## עדכון מחלקות, שעות, טלפונים ומיילים

כל הנתונים נמצאים במקום אחד: [`js/departments-data.js`](js/departments-data.js).
כל מחלקה היא אובייקט עם שם, כתובת, טלפונים, מייל, ושעות קבלה (`schedule`)
לפי ימים בשבוע. כדי לעדכן - עורכים את הקובץ הזה בלבד, אין צורך לגעת בשאר
הקוד. כמה מחלקות מסומנות `onlineBookingAvailable: false` כי לא סופקו להן
שעות קבועות (לשכת ראש העיר, וטרינר עירוני) - הן יוצגו עם פרטי קשר בלבד עד
שיושלמו שעות מדויקות.

## הפעלת שליחת מיילים אוטומטית (EmailJS)

בלי הגדרה, המערכת עדיין עובדת במלואה - היא רק מציגה לתושב קישור מוכן
לשליחת מייל ידנית (`mailto`) במקום לשלוח אוטומטית, כך שהמידע לא הולך
לאיבוד. כדי להפעיל שליחה אוטומטית אמיתית:

1. פותחים חשבון חינמי ב-[emailjs.com](https://www.emailjs.com) (עד 200
   מיילים בחודש בחינם).
2. מחברים שירות מייל (Gmail / Outlook / SMTP) תחת "Email Services".
3. יוצרים שני תבניות מייל (Templates):
   - תבנית למחלקה - עם המשתנים: `to_email`, `department_name`,
     `citizen_name`, `citizen_phone`, `citizen_email`, `appointment_date`,
     `appointment_time`, `notes`.
   - תבנית לתושב - עם המשתנים: `to_email`, `citizen_name`,
     `department_name`, `appointment_date`, `appointment_time`.
4. מעתיקים את ה-Public Key, Service ID ושני ה-Template ID אל
   [`js/email-config.js`](js/email-config.js) ומשנים `enabled: true`.

## מגבלה אדריכלית חשובה

זוהי מערכת **פרונטאנד בלבד**, ללא שרת ובלי בסיס נתונים משותף - כפי שנבחר
בהתאם לצורך הנוכחי. המשמעות המעשית:

- **החזקת המשבצת ל-15 דקות ורשימת "התורים שלי" נשמרות ב-`localStorage` של
  הדפדפן, בלבד.** זה מונע כפילות תור **באותו דפדפן/מכשיר**, ונותן לתושב
  את חוויית הטיימר של 15 דקות - אבל **אינו מונע** מצב שבו שני תושבים
  שונים, כל אחד מהמכשיר שלו, בוחרים בו-זמנית את אותה משבצת בדיוק ושניהם
  "מצליחים" להזמין אותה. מניעת התנגשות אמיתית בין תושבים שונים דורשת
  מקור אמת משותף - כלומר שרת/מסד נתונים מרכזי (למשל Node.js+DB, או
  Firebase/Supabase).
- שליחת המייל דורשת חשבון EmailJS (או חלופה), כמתואר למעלה. שליחת SMS
  אמיתית לא נכללת בגרסה זו - כל שירותי ה-SMS (כגון Twilio) דורשים שרת
  שמחזיק את פרטי ההתחברות, כדי לא לחשוף אותם בקוד הצד-לקוח.

**מסקנה מעשית:** הגרסה הזו מצוינת להרצה פנימית, הדגמה, או שימוש בהיקף
קטן שבו הסיכוי להתנגשות על אותה משבצת נמוך. לפני הפעלה מבצעית מול כלל
תושבי העיר, מומלץ להוסיף שרת קל (למשל Node.js + מסד נתונים, או שירות
Serverless) שישמש כמקור אמת יחיד לזמינות המשבצות - כדי למנוע קביעת אותו
תור פעמיים בפועל.

## מבנה הפרויקט

```
booking/
├── index.html              # נקודת הכניסה
├── css/styles.css          # עיצוב, RTL, פלטת טירת כרמל
├── js/
│   ├── departments-data.js # קובץ הקונפיגורציה היחיד לעריכה - מחלקות/שעות/קשר
│   ├── scheduler.js        # חישוב משבצות זמן פנויות מתוך שעות הקבלה
│   ├── store.js            # החזקת משבצת ל-15 דקות ואישור תורים ב-localStorage
│   ├── email-config.js     # פרטי חיבור ל-EmailJS (לעריכה)
│   ├── email.js            # שליחת מייל למחלקה/לתושב + הורדת קובץ ICS
│   └── app.js              # ממשק המשתמש המלא
└── README.md                # הקובץ הזה
```
